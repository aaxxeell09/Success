## Méthode

- Dates de naissance relevées dans l'infobox Wikipédia (anglais) et recoupées par une seconde source quand elle existe (NASA, Fondation Mandela, biographie vaticane).
- Textes rédigés à partir des seules phrases des sources citées ; une information présente dans une seule source secondaire est écartée ou signalée.
- Longueur : 20 à 40 mots environ (jusqu'à environ 55 pour les deux frères Collison), moins de 400 caractères.

## Intégration

`data/at25.json` est un objet `{ "<id>": { "at25": "...", "at25_sources": ["https://..."] } }`. Pour afficher la section, copier `at25` et `at25_sources` dans l'histoire de même `id` de `stories.json` (et de sa copie embarquée dans le widget).
